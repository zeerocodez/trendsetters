# The Trendsetters Schools — Official Website

> **Inspiring Creativity, Nurturing Pacesetters**  
> *Pioneering a new trend in education.*

A modern, accessible web application for **The Trendsetters Schools** (Uyo, Akwa Ibom State, Nigeria), built with the school's signature 2-color brand identity: **Academic Royal Navy** & **Warm Amber Gold**, featuring a clean, prestigious, parent-welcoming layout.

---

## 🌟 Key Highlights & Features

- **Montessori Curriculum & Early Reading Acceleration:** Individualized sensorial learning and synthetic phonics mastery.
- **10+ Hours Daily Childcare:** Operational from 7:00 AM to 6:00 PM with structured learning, hot organic meals, resting suites, and after-school enrichment.
- **Family Sibling Concessions:** Special multi-child fee discounts (10%, 15%, 20% savings) highlighted for prospective parents.
- **Campus Life Gallery & Lightbox:** Filterable gallery featuring authentic moments from graduation ceremonies, ballet recitals, aviation field trips, and classrooms.
- **Multi-Step Online Admissions & Tour Wizard:** Seamless 4-step modal application system with instant Reference ID generation.
- **Direct WhatsApp Chat Integration:** One-click communication with admissions counselors.

## 🚀 Getting Started

### Local Development
To run the website locally on your machine:

1. **Option A (PowerShell Local Server):**
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\serve.ps1
   ```
   Open `http://localhost:5500/` in your browser.

2. **Option B (Direct File):**
   Double click `index.html` or open it directly in any modern browser.
